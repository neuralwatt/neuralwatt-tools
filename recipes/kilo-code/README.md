# Kilo Code with Neuralwatt

Kilo Code lists Neuralwatt as a built-in provider. Choose Neuralwatt and enter your API key. The [integrations overview](https://docs.neuralwatt.com/integrations/overview#pick-your-tool) lists the other tools we document.

To add a `/nw-usage` command, put the command block from [nw-usage](../../scripts/README.md#opencode-command) in `~/.config/kilo/kilo.json`. Kilo Code uses the same command format as OpenCode.
